# The Beer Doctor: website

Published with GitHub Pages at https://the-beer-doctor-games.github.io (the repository must be named
`the-beer-doctor-games.github.io` so the site and `app-ads.txt` live at the root of the domain).

- `index.html`: studio page listing the games.
- `app-ads.txt`: one file for all apps (AdMob checks it at the root of the website in the store listing).
- `<game>/privacy/`, `<game>/terms/`: legal pages per game. For a new game, copy a folder and add a card
  to `index.html`.
